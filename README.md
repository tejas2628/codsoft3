# Temperature Converter

A small browser utility that converts between Celsius, Fahrenheit and Kelvin. Built during a web development internship with Codsoft (2023).

Vanilla JavaScript, no dependencies.

## Files

| File | Purpose |
|---|---|
| `temperature.html` | Markup and input form |
| `tc.css` | Styling |
| `tc.js` | Conversion logic |

## Running it

Open `temperature.html` in any browser.
